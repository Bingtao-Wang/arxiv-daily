# MFM-VL 项目画像、评分与精读

MFM-VL 机械臂项目要把已有“移动感知”能力扩展为“移动 + 实体操作”闭环，补齐视觉语言导航之外的真实场景交互能力。论文跟踪围绕操作精度、工作空间适配、数据链路打通，以及从数据采集、模型训练到真机部署的完整能力链展开。

## 三阶段目标

| 阶段 | 硬件载体与目标 | 优先阅读内容 |
| --- | --- | --- |
| 第一阶段 | 固定桌面机械臂，建立可复现的操作基线 | 示范采集、标定和同步；ACT / Diffusion Policy；精细操作；真实硬件闭环 |
| 第二阶段 | 轮式移动平台，完成场景化操作任务 | 底盘—机械臂协同；工作空间与可达性；移动操作数据；语言任务到动作执行 |
| 第三阶段 | 轮足机械狗，在复杂地形执行操作 | 轮 / 腿 / 臂联合建模；WBC；接触和平衡；负载变化；机载部署与状态反馈 |

三阶段是能力发展路线，不表示后一阶段已经完成硬件适配。桌面数据与策略基线、轮式移动操作和轮足全身控制都具有阅读价值，不给第一阶段设置固定排序加成。跨载体方法可能同时服务多个阶段。

## 页面项目相关性：0–100 分

评分实现在 `shared/project.ts`。全局分数与下列五个维度只读取 `IPaper.title` 与 `IPaper.sourceAbstract`。`titleZh`、中文摘要和解析、`relevance`、标签、旧 `score` 均不参与；这样中文生成建议不会变成给论文自身加分的证据。经人工核对全文的明确载体证据只用于校正对应**阶段分与阶段标签**，不改写全局分和五维证据。

| 维度 | 满分 | 主要证据 |
| --- | ---: | --- |
| 操作精度与策略 | 20 | 机械臂 / 抓取 / 实体操作，操作策略，精细控制与接触约束 |
| 载体与工作空间 | 25 | 桌面、轮式、轮足 / 四足操作的明确载体，工作空间及跨载体证据 |
| 数据链路 | 20 | 数据集与示范、遥操作、标定同步、动作表示和跨载体数据 |
| 训练到部署 | 20 | 训练或微调、真实机器人验证、延迟与部署效率 |
| 场景任务闭环 | 15 | 视觉语言动作、反馈、具体场景操作及移动 / 全身协同 |

全局分数是五个维度的实际得分之和。每个正分维度提供对应原始文本摘录；页面展示这些摘录作为核验入口。方法按概念是否出现计分，相同词重复二十次不会增加得分。不同维度描述互补的能力证据，分数不能解释为某个任务成功率。

实体操作是核心条件：只有导航、步态、人形行走或腿部 WBC 时，整体得分保持较低；出现“轮足”但没有操作证据不会被判定为轮足机械臂系统。轮式移动操作也需要操作相关证据。仅有人形操作的平台匹配更保守，不推断为四足或轮足验证。

缺少原文摘要时按标题证据折减到相应原始维度得分的约 70%，并注明证据不足。规则会过滤部分明确否定，例如 `no offline training`、`training-free`，也过滤常见背景句中的训练描述；这是文本规则，不能完整理解所有否定、对比和方法归属。

## 分阶段分数与排序

全局分用于默认全站排序。阅读列表先要求全局分至少 50 分；阶段筛选还要求所选阶段分至少 50 分，并使用该阶段分数排序。最低分可提高至 70 或 85 分，重置后恢复 50 分。原始采集库、既有收藏快照与详情直链保留，以便评分规则更新后重新判断。阶段评分在共同方法价值上替换载体匹配分，再对仅有间接迁移证据的情况折减，并返回该阶段的中文理由。

原文明示桌面 / 移动 / 轮足机械臂操作的方案与可迁移组件会拉开差距。泛化数据接口或策略方法可以同时关联多个阶段；最佳阶段并列时不强行指定唯一阶段。多数论文按标题和摘要证据计算阶段分；若详情记录了正文定位明确的 `verifiedEmbodiment`，相应阶段可按已核验载体校正，其他阶段仍需遵守迁移边界。分数表示主题与方法价值，不代替对具体硬件实验的核验。

`stageMatches` 另外提供每阶段的关联类型和标签，避免用分数推断已经验证的载体：

| 类型 | 含义与页面处理 |
| --- | --- |
| `direct` | 原文直接涉及对应载体或操作主题；仅出现移动操作时注明“底盘待核”，仅有腿式操作时注明“轮足待核” |
| `transfer` | 操作 / 数据 / 策略方法可供迁移，不视为该阶段硬件验证；没有其他直接关联时，首页统一显示“跨阶段方法参考” |
| `foundation` | 轮足或四足运动控制的基础价值；标签与理由说明是否缺少机械臂操作证据 |
| `none` | 没有足够关联，不展示阶段标签 |

首页展示 `direct` / `foundation` 标签，不会因为三个阶段分数都超过某个阈值就把三类硬件标签全部挂上。`single-arm`、`bimanual`、`mobile manipulation` 和 `wheeled-quadruped` 等隐含机器人上下文也参与识别，不强制摘要必须出现单独的 `robot` 一词。

腿式机器人的 WBC 是第三阶段的重要基础，因此腿式但无臂的论文可得到第三阶段的基础参考分，最高约 45 分，整体操作相关性仍较低。例如 LLA-MPPI 研究四足 Go2 的模型适配与控制，可以帮助构建后续 WBC 层，但不能证明轮足、机械臂或视觉语言操作能力。由此产生的阶段分数可能高于全局分数，两者表示不同阅读视角。

VOMMI 是全文校正的具体例子：摘要说明移动操作，但未明确底盘形态；官方 v1 §VI-A 写明真机为轮足 DeepRobotics M20S＋CM1 机械臂。站点据此将第三阶段标为“轮足机械臂真机验证”，把第二阶段视作轮式平台的数据与策略迁移参考，而不把 M20S 实验误称为轮式平台实验。VOMMI 研究便携示教、视觉里程计和 VLA 动作接口，未公开轮足动力学 WBC 方法，因此“第三阶段直接载体验证”也不表示已解决复杂地形全身控制。

同分时按全局分数、较新发布日期、arXiv ID 稳定排序。排序函数返回新数组，不改写原始数据。采集脚本保留的旧规则分只负责候选召回，与上述页面评分分开。

## 收藏与数据范围

收藏保存在当前浏览器、当前站点来源的 `localStorage`，包括无版本后缀的 arXiv ID 与论文快照。这样已收藏论文即使离开当前采集窗口，仍有本地详情可读；现有数据可用时优先显示现有数据。收藏支持刷新保留和同源标签页同步，不提供账户、服务器备份或跨设备同步。

更换域名 / 端口、浏览器或清理站点数据会影响收藏可见性。若浏览器拒绝存储或写入失败，界面保留本页选择并提示持久化失败，不宣称已经永久保存。

## 评分的使用边界

当前评分是透明、确定性的文本匹配，不是经过用户偏好训练的语义推荐模型。它可能遗漏新术语，或把摘要提到的背景方法误当为相关证据；已有否定规则只能降低部分误判。摘要未写出的硬件、训练细节与实验能力不会自动补齐。

论文最终是否适用，应结合详情中的来源、正文实验条件和项目自身硬件验证。不要把高相关性等同于论文质量高、代码开源、模型可下载、许可适配或能够直接部署。关键词召回也不是完整文献覆盖保证。

`scripts/project.test.ts` 覆盖三阶段区分、桌面基线与轮足 WBC、纯导航 / 纯腿部控制抑制、隐含机器人上下文、载体标签与迁移参考区分、中文字段隔离、重复关键词不增分、否定措辞、标题证据不足、排序稳定性与分数边界。调整评分时，应同时检查真实论文的证据摘录及这些回归案例。
